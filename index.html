三维空间描述语言 · 原型
拖动旋转 · 右键平移 · 滚轮缩放 · 点击物体定位到源码

    概念由 concept 名字 = 集合表达式 定义，求解后按几何与空间事实识别。点击高亮成员。

    从求解后的几何中反向读出的关系，用的是同一套语言。点击高亮两者。

      实体

      box size=w,h,d长方体（原点在底面中心）
      cyl r= h= axis=y · cone r= r2= h=圆柱 / 圆台，可沿 x / y / z
      sphere r= · wedge size=w,h,d球 / 楔形（+x 侧高）
      span from=A to=B section=w,t连接两点的实体；r= 圆杆，steps=n 台阶
      span from=A drop=B从 A 竖直向下延伸到 B 的面（立柱）
      revolve profile=[(r,y); …] smooth=true轮廓绕竖直轴旋转成体
      sweep path=C profile=rect section=w,t截面沿曲线扫掠；profile=circle r= 圆管；profile=[(u,v);…] 任意截面
      pipe path=[A; B; C] r=管线简写，拐角自动倒圆

      曲线（不是实体）

      arc r= angle=a0,a1 rise= plane=xz|xy|zy圆弧；0° 指向 +x，俯视逆时针
      helix r= pitch= turns=螺旋线
      bezier path=[…] · spline path=[…] closed=true · line贝塞尔 / 过点样条 / 折线
      C.start C.mid C.end C[0.3]曲线上按弧长取点
      repeat n= along=C orient=yaw|full|none沿曲线分布，局部 x 跟随切线

      镜像与旋转（副本跟随原物体）

      mirror R of=A across=B axis=x · across=B.topR 是 A 关于平面的镜像（手性翻转）
      mirror across=x { … }对称组，副本在 .mirrored 下
      rotate R of=A about=B axis=z angle=90R 是 A 绕任意轴旋转的像
      rotate n=5 about=B axis=… { … }旋转对称，副本在 .r1… 下

      关系（决定位置）

      on=B · under=B放在 B 上面 / 下面
      against=B.left贴住 B 的某个面（自动选择自己朝向它的面）
      inside=B中心对中心放入 B
      at=x,y,z · at=B.top把自己的 pin（默认底面中心）放到某点
      align=left,back再与参照物的这些面对齐（或 x/y/z 中心对齐）
      gap= · offset=x,y,z沿法线留空 / 平移

      朝向（都绕 pin 点转）

      turn= · tilt= · roll=绕竖直轴 / 顶部倒向前 / 顶部倒向右（度）
      rot=(x,y,z,deg)绕任意轴
      aim=B aimwith=top让某个面指向目标，尽量保持直立
      on / against 等关系继承参照物的三维朝向，角度都相对参照物

      锚点

      B.top B.top-left-front B.origin面 / 棱 / 角 / 原点；也可用 east west north south
      B[u,v,w]包围盒内的归一化坐标，-1..1
      B.top+(0,2,0)锚点加偏移
      B.w B.h B.dB 的尺寸，可用于表达式
      B.top.y · B.x锚点在当前父坐标系里的坐标分量

      变量与集合

      let h = 12 · let t = pad.top变量：数、向量、对象、集合；块内可见，惰性求值
      #wall · kind(box, house) · a.*.b · all()集合：按标签 / 类型（含模板名）/ 路径通配
      A | B · A & B · A - B并 / 交 / 差
      S where h > 2 and kind == "box"按成员属性筛选（w h d x y z kind name it）
      on(S, k) · supports(S) · against(S) · inside(S) · contains(S) · touching(S)按空间关系筛选（求解后才有，k 为至少几个）
      concept pier = kind(cyl) & on(ground)用集合定义新语义，求解后识别
      style pier mat=stone按集合改材质（后写覆盖先写）
      check "说明" pier - on(ground)检查：集合为空或条件为真即通过
      repeat over=#pillar { … on=it }对每个成员各做一次，it 指向成员
      on=#wall集合也能当参照物（用总包围盒）
      sin cos sqrt min max abs round count · a % b函数（角度用度）与取余

      多对象模式与变体

      pattern gate(a, b, top) { a in … ; top on a ; top on b }多个角色之间的关系，搜索所有匹配；一个对象不同时扮演两个角色
      pattern room(floor, walls*, roof) { walls on floor ; count(walls) >= 3 }* 是集合角色：满足约束的全部成员
      room.walls · count(room)取某个角色的全部绑定 / 匹配次数
      variant deck use=planks gap=0.1按语义换成另一个模板；外包络不变（模板收到 w h d）

      编译期的随机与条件（不是运行时）

      let seed = 7 · rand() · uniform(a, b) · choose(x, y, z)确定性随机：hash(种子, 调用位置, 键)，同源码同结果
      if cond { … } else if … { … } else { … }展开时选择结构（参数、let、下标、随机数）
      if(cond, a, b)表达式里的选择

      构造

      group · union · subtract · intersect分组与布尔运算（subtract = 第一个减去其余）
      repeat n=4 step=x,y,z turn= center=true阵列；n=(2,1,3) 为网格；子语句可用 i j k idx
      def name(p=默认) { … }参数化模板，用 name id p=值 实例化
      material name color= metal= rough= opacity=材质，用 mat=name 引用
      #tag任意标签（语义由使用者赋予，不影响几何）
